The active project is [np-finance](https://github.com/aberson/np-finance).
Use `uv run np-finance`; this archive is historical and is not an install target.

[source-e65e848.zip](source-e65e848.zip) preserves all 229 tracked files from
pre-rename commit `e65e848dfb28eb3bb801bbaa2860e9404b43e30a`, with their original
names and terminology. Its members were byte-compared against Git objects.
SHA-256: `671edd87ff737af603fa872fcfb86916347859e56a2ca05307676962a7c3372e`.

The ZIP contains public source only: no Git database, local environments,
credentials, private configuration, mail archives, or generated financial reports.
History and issues remain in the renamed repository. GitHub redirects the old URL
to that same repository; there is no separate old repository to delete or archive.

The old command `pta-finance` is deprecated for new instructions but retained as
a compatibility alias. Existing schema markers, credentials and cloud resource
identifiers remain stable, as described in [the migration guide](../../project-rename.md).

empty hidden `.git` directory remains there; no source or financial data remains.
